# Child-Appropriate Clipart

This folder stores local lesson artwork used by the tutoring website.

## Rules for images in this folder

- Images must be appropriate for elementary-age students.
- Images should match the lesson context and help keep students engaged without distracting from reading.
- Avoid frightening, violent, sexual, political, or otherwise age-inappropriate imagery.
- Prefer simple line art, friendly educational illustrations, or public-domain/open-license artwork.
- Store images locally in this folder rather than hot-linking so the tutoring site remains reliable.
- For third-party artwork, record the original source and license in this file before adding it.
