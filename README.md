# Detroit Tutoring

A browser-based tutoring session hub designed around this tutoring sequence:

1. Read an IRL book together for about 5 minutes — **no website timer**
2. Complete one section of **Fast Start for Early Readers**
3. Complete the selected **Project Read** lesson

## Current version

The first version includes:

- Responsive GitHub Pages-ready interface
- Session Mode
- No timer for the IRL book step
- All 60 Fast Start lesson titles
- Fast Start lesson routing and four-part flow
- Project Read Lessons 1–14, including 13A, 13B, and 13C
- Tutor-controlled lesson selection
- Local browser progress/checkmarks
- Curriculum placeholders ready for exact source transcription

## Content fidelity

The supplied Fast Start and Project Read materials are the source of truth. Curriculum wording should not be paraphrased or silently corrected when lesson content is added.

Project Read short-vowel symbols must remain exact:

- ă
- ĭ
- ŏ
- ĕ
- ŭ

## Hosting

The site is structured as a static HTML/CSS/JavaScript project and can be hosted directly with GitHub Pages.
